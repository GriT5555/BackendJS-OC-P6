# Javascript - Back-end building.

## **Développer la logique back-end d'un site de notation de livres.**

#### Élaboration de la logique backend d'un site de notation de livres, préparation d'un server Express et d'une base de données MongoDB.  Réalisation des modèles selon lesquels les données s'organiseront dans la base de données, utilisation de middlewares et contrôleurs appelés via un routeur selon les requêtes utilisateurs, de login et de notation.  Qui dit login, dit donc aussi identifiants et cryptage, introduction à la cybersécurité et sécurisation de données. Arithmétique et algorithmes de base.
